# Local instructions

This is an index of local instructions that apply to just this project.

* Ensure consistency across this file with respect to the global instructions.
* This file should be considered an index of local instructions.
* Each file other than this one should be named in the format `<category>.instructions.md` where `<category>` is the category of the file and all related rules should be listed there.
* `<category>.instructions.md` files should be placed in this directory.
* `<category>.instructions.md` files should maintain a backlink to this file.
* If this is the [git@github.com:credfeto/cs-template.git](https://github.com/credfeto/cs-template) repository, this folder should not have any other instructions than this file.
* This file should not be modified in [git@github.com:credfeto/cs-template.git](https://github.com/credfeto/cs-template), but can be modified in forks and other repositories as needed.
* The rules above this point in the file should be considered global rules.

Load when adding, removing, or changing which fields `fingerprint_issue_json` or `fingerprint_pr_json` (`lib/fingerprints`) hash, or when investigating why an Issue/PR is stuck as "unchanged".
* [Development Guides](development-guides.instructions.md) - the repository development guide (`docs/development/README.md`), the per-script guides, `lib.md` and `claude-hooks.md`: read the relevant guide before changing a script, `lib/*` module, hook or test, and update it in the same PR as any behaviour change. Load when changing any script, `lib/*` module, Claude Code hook or `*.bats` test in this repository, or adding a script.
* [Time Reporting](time-reporting.instructions.md) - clock times reported to humans must be local time with zone abbreviation, never `date -u`, and never mixed with UTC; UTC only for machine comparisons. Load when starting any session in this repository.
* [Issue Titles](issue-titles.instructions.md) - the `<scope>: <rest>` issue title format, how to choose the scope for each component, and dropping Conventional Commits types and category words. Load when creating or renaming an issue in this repository, or opening a pull request for one.
