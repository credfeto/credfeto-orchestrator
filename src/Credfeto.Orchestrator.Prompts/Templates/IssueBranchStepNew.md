When ready to start work: create a new branch BEFORE making any changes to the repo, commit a placeholder CHANGELOG.md entry, push upstream, and create a draft pull request. The PR body MUST include the line "Closes #{{item_id}}" so GitHub automatically closes the issue when the PR is merged. Create it with cfwf (it is always a draft, and cfwf puts it on the Workflow board as Development): cfwf pr create --repo {{repo_full}} --head <branch> --title "<type>(<scope>): <description>" --body-file - <<'BODY' then the body, ending with the line Closes #{{item_id}}, then BODY on its own line. {{board_note}}
